GARAGE MANAGEMENT PRO - Admin / Boss
=======================================

Install this on the boss's / manager's PC. Only one install needed.

1. Run the .exe. Windows may show "Windows protected your PC" -
   click "More info" then "Run anyway" (the installer is unsigned,
   this is expected).
2. Follow the installer.
3. Sign in with your manager account.
4. A tray icon appears near the clock. Closing the window hides it
   there rather than quitting, so notifications keep arriving - use
   the tray icon's right-click menu to actually quit.

You will get a desktop notification whenever a new client is
checked in or stock changes at reception/stock, even if this
window is minimised.
