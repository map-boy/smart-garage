C & V SMART GARAGE - Reception & Stock (Portable, no install)
================================================================

Use this ONLY if the regular installer in the other folder gives a
"WebView2Loader.dll was not found" error.

1. Copy this whole folder anywhere on the laptop (Desktop is fine).
   Both files must stay together in the same folder.
2. Right-click garage-desk.exe -> Properties -> if there is an
   "Unblock" checkbox near the bottom, tick it, then OK.
3. Double-click garage-desk.exe to run.

If it still shows the same error after that, the laptop is missing
Microsoft Edge WebView2 Runtime entirely. Ask for help getting that
installed once - after that this will always work.
